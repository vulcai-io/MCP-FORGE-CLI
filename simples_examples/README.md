# Generated examples — best results

This folder gathers, for every source type supported by mcp-forge, the
best result obtained across all correction and stability-test loops
(`_raw_results*.json` from the private development repo) — selected
automatically by the highest `eval_score` among successful runs.

Each subfolder under `results/` is a complete, self-contained MCP server,
exactly as generated by mcp-forge (`server.py`, `README.md`, `USAGE.md`,
`requirements.txt`, `eval_report.json`) — nothing has been hand-edited
except each folder's `README.md`, which now has a short summary prepended
(source, score, what it demonstrates) on top of the original generated
content.
